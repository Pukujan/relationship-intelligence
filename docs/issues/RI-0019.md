### Summary
Connector routing, 3-cadence automations (per-day, per-event, continuous signals), 4-zone human–agent co-design & plan-locking model, and an extensible agent system supporting templates, pre-built agents, and user-built custom agents/automations.

## PDD
Users connect personal tools once (Gmail, Calendar, LinkedIn, Wispr Flow, Riley voice) and route signals cleanly into Workspaces and Projects without manual re-auth. Humans own North Star **Objectives** and hard deadlines; agents handle triage/ranking, daily briefs, and pre/post-event prep. Users can start with pre-built agents (Chief of Staff, Event Prep, Researcher, Outreach) or starter templates, collaborate with agents in a **Draft Plan → Lock** co-design flow, and build their own custom agents/automations with explicit approval guardrails.

## SDD
1. **3-Tier Connector & Automation Ownership:**
   - **User-level connectors:** Personal Gmail, Google Calendar, LinkedIn, Wispr Flow, Riley voice — authorized once per `app_user`, routed by rule (`sender/domain/keyword/calendar`) into a target `workspace_id` + `project_id` (unmatched items land in Personal triage).
   - **Workspace-level:** Shared team connectors (Drive, Discord/Slack, Luma org), workspace agent roster, and autonomy policy defaults.
   - **Project-level:** Objectives, Events, Missions, Plans, Tasks, and project-scoped automations.
2. **Three Predictable Cadences:**
   - **Per-day (Chief of Staff):** Morning Glance brief (top 3 moves) + evening sweep (progress, stalls, tomorrow's prep). Read-only.
   - **Per-event (Calendar + Event Agent):** Automated checkpoints at **T−7d** (attendees/speakers enrichment + top people to meet), **T−24h** (one-page prep brief + intro paths), and **T+24h** (notes/voice capture + queued thank-yous/follow-ups).
   - **Continuous signals:** Connector events classified, deduplicated, and attached to Person/Project; only goal/deadline-impacting changes surface as proposals.
3. **Human vs. Agent Decision Rights (4 Autonomy Zones):**
   - **Zone 1 — Sense & Prep (Agent autonomous):** Sync, enrich, web/event research, daily/event briefs, cooling-contact detection. Zero external side effects.
   - **Zone 2 — Suggest (Agent proposes → Human triages):** Draft outreach, intro suggestions, new tasks, reschedules → queued in **Approvals** with Do/Don't preview (`Approve`, `Stop`, `Re-plan`, `Snooze`).
   - **Zone 3 — Co-Design & Lock (Human + Agent together):** Scoping Projects, setting Objectives, joint deep research, shaping multi-step Plans. Stays a mutable **Draft Plan** until the user clicks **Lock / Approve Plan**, freezing it into tracked `mission` + `plan` + `task` rows.
   - **Zone 4 — Commit & Act (Human final say):** External sends (email/DM/invites), goal/budget changes, role/member changes — gated unless explicitly opted into auto-run.
4. **Templates, Pre-Built Agents & Custom Agent Builder:**
   - **Pre-built agents:** Workspace ships ready-to-use agents (Chief of Staff, Event Prep, Research Analyst, Relationship Outreach) modeled after first-class teammates (cf. Linear Agents, Asana AI Teammates, Dust default agents).
   - **Template gallery:** One-click starter templates for recurring project/event/outreach workflows (cf. Notion Custom Agent Templates, ClickUp Autopilot/Super Agent templates, Lindy templates).
   - **Custom agent & automation builder:** Conversational + form/YAML builder (cf. Dust Sidekick, Asana AI Studio, Notion Custom Agents) where users specify triggers (daily/event/signal), connected tools/MCP servers, scoped workspace/project knowledge, and per-step human-in-the-loop approval checkpoints (cf. Relay.app pattern), testable in a private sandbox before publishing to the workspace.

## Eval / Completion Oracle
Connector routing rules route test Gmail/Calendar events to the right Workspace/Project without cross-workspace leaks; per-event T−7d/T−24h/T+24h jobs generate read-only briefs and queued approvals; a Co-Design Draft Plan produces zero tasks until explicitly locked; a user can instantiate a template agent and create a custom trigger-based agent with an approval gate.
