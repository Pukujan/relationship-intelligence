Relationship Intelligence — how it works

Design overview. Boxes are components; arrows are data flow. Nothing here is built yet except Octo and the coordination stack.

1 · What the system is

A browser window onto Octo. Octo already stores facts, files, and the graph — the app only displays them. Agents and n8n talk to Octo directly, not through the app.

not built a social network · a new database · a new auth system · a new graph engine · a scraping platform

2 · The one flow we build first

Upload → review → person page with sources. Everything else waits for your acceptance of a later slice.

3 · What we are NOT building now

Later slices each need your acceptance before any code is written. The bottom row is never in scope.

4 · How identity decisions work

The model never merges on a name. You decide, or the records stay separate.

5 · How an agent answer is produced (later slice)

Answers cite evidence. Missing evidence is stated, never guessed.

6 · How work gets delivered (the ACS stack, already installed)

Issues own scope. A required check named gates must pass on the exact commit before merge. Merged code is the only accepted code.
